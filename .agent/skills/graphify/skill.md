# Skill Context — Portfolio Responsive Neo-Brutalist Frontend

## Identity

Adith — CSE student, builder, backend-focused engineer with strong design taste. Portfolio should feel bold, sharp, premium, unconventional, memorable.

## Current Project

Personal portfolio website.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion (preferred for animations)

## Design Direction

Neo-brutalism with modern polish.

### Core Feel

- Aggressive
- Bold
- High contrast
- Clean geometry
- Editorial / poster-like
- Strong personality
- Premium student-founder vibe

## Visual Language

### Colors

Primary palette:

- Black `#050505`
- Off white `#F1EEE6`
- Bright orange `#FF4D00`
- Acid lime `#D7F000`
- Muted steel blue `#7EA0BE`

Avoid:

- Purple
- Generic gradients
- Soft pastel startup colors

### Typography

- Massive condensed hero text
- Bold uppercase headings
- Monospace / pixel / technical supporting text
- Tight spacing with intentional rhythm

### Borders / Shapes

- Thick black borders
- Hard corners mostly
- Offset shadows
- Layered cards
- Brutalist blocks

## Hero Section Rules

### Desktop

Split screen:

- Left black panel = text / CTA
- Right blue panel = image / badge

### Mobile

Stacked but compact:

1. Navbar
2. Hero text
3. CTA
4. Image panel
5. Stats
6. Ticker visible first screen

### Tablet

Mini-desktop:

- 2 column layout
- Text left
- Image right
- Stats below
- Ticker visible

## Important UI Elements

### CTA Button

- Large block button
- Offset orange shadow
- Strong hover motion

### Badge

Text: OPEN TO INTERN

Should overlap image frame slightly.

### Stats Cards

Examples:

- 3+ YEARS BUILDING
- 12 PROJECTS SHIPPED

### Ticker

Scrolling bottom bar:
OPEN TO INTERN • BACKEND ENGINEER • CLEAN CODE • PRESSURE TESTED BUILDS

## Motion Style

Use Framer Motion.

Preferred animations:

- Slide in
- Stagger reveal
- Sharp hover translate
- Ticker motion
- Slight image rise/parallax

Avoid:

- Soft fades only
- Floaty startup animations
- Excessive blur

## Coding Preferences

- Clean reusable React components
- Tailwind utilities
- Responsive-first logic
- Minimal clutter
- Maintainable structure

## What AI Should Help With

- Responsive layouts
- Tablet fixes
- Hero polish
- Motion systems
- UI refinement
- Tailwind cleanup
- Component architecture

## What AI Should Avoid

- Random redesigns
- Pastel SaaS aesthetics
- Generic templates
- Over-rounded cards
- Minimal boring layouts
- Breaking desktop while fixing mobile

## Output Standard

Should look like a designer-engineer portfolio, not student template.
